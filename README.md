## 买完必须做的五件事

买到号不等于用完就没事。这几步顺序错了，号可能当场就丢。

**一、只在 App Store 登录，不进“设置”。** 打开 App Store，点右上角头像，下拉到底退出当前账号，滑到最上方输入新账号密码。iCloud、照片、通讯录全部保持你自己的 ID 不动。把陌生 Apple ID 登进“设置”顶层，有锁机风险，这是最容易出事的一步。

**二、下载完就切回自己的主 ID。** 已下载的 App 不会因为切号消失，正常用。只有更新时需要重新登录当初下载它的那个账号。

**三、改密码之前，先把账号绑成自己的手机号。** 这是最容易搞砸的地方。成品号原来绑的是虚拟号，你要是先去 appleid.apple.com 改密码，验证码会发到那个你收不到的号上，改到一半卡死，号就等于废了。正确顺序是：登录 appleid.apple.com，进“安全”板块，先添加自己的手机号为受信任号码并完成验证，再改密码，最后同步更新密保问题答案。

**四、开双重认证，绑一个救援邮箱。** 救援邮箱建议和主邮箱用不同服务商（主用 Gmail，救援用 Outlook 之类），主邮箱丢了还能找回来。三个密保问题的答案截图存好。

**五、第一周别急着订阅。** 新号上来就绑卡订阅付费服务，触发风控的概率明显更高。先每天登一次 App Store，浏览一下，下 1 到 2 个免费 App，第 8 天再考虑订阅。这个节奏比什么“养号技巧”都实在。

另外，尽量固定用同一地区的网络节点登录，别今天美区 IP、明天国区 IP 来回切。

3 天售后期只覆盖“到手就是坏的”这种情况（账密错误、登不上），改密改绑之后出的问题不在范围内。所以上面第三步一定别跳。
